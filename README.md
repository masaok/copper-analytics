# Copper Analytics

Cookieless, privacy-first traffic analytics for all of your projects, on one dashboard.

The design is in [docs/PLAN.md](docs/PLAN.md). Agent rules are in [AGENTS.md](AGENTS.md), and the process for people is in [CONTRIBUTING.md](CONTRIBUTING.md).

## Develop

```bash
pnpm install
pnpm verify   # lint, checks, typecheck, tests, build
```
