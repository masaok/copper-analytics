# Changelog

## 0.1.0, 2026-10-04

The first public version.

- All-projects overview with live visitors, today against yesterday and a 30-day trend.
- Project reports: visitors, pageviews, visits, bounce rate, top pages, referrers, countries, devices, browsers, operating systems and UTM sources, over Today, 24 hours, 7 days, 30 days, 12 months or a custom range.
- Read-only share links, CSV export and a stats API with per-project tokens.
- `c.js`, a 482-byte tracker that follows single-page navigation.
- Two deploy modes: simple (one Node process and any Postgres) and edge (Cloudflare Worker, Durable Objects and Neon).
- GitHub sign-in, and Google sign-in when its credentials are set.
- `@copper-analytics/next`, a component for Next.js.
